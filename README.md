### 🌟 Featured project: [GitHub Float](https://github.com/vinimcorrea/github-float)

<a href="https://github.com/vinimcorrea/github-float">
  <img src="https://raw.githubusercontent.com/vinimcorrea/github-float/main/docs/social-preview.png" width="100%" alt="GitHub Float">
</a>

An always-on-top native macOS panel for your **GitHub Project code reviews**: what you put in review, who is reviewing it, and which teammates' PRs still need a reviewer. I built it because PRs were sitting in review for days unnoticed.

- **Native Swift + SwiftUI.** No Electron, a few MB, ~0% CPU.
- **Efficient.** One paginated GraphQL query per poll, pauses on sleep, exponential backoff.
- **Smart notifications** for new reviews, changes requested, failing CI and merged PRs.
- **Fully shipped:** universal binary, CI, automated GitHub releases and a Homebrew tap that updates itself.

```bash
brew install --cask vinimcorrea/tap/github-float
```
